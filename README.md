# .NET PDF Generator (.NET 9 + PuppeteerSharp + RazorLight)

This is an ASP.NET Core Web API project using **.NET 9**, **RazorLight**, and **PuppeteerSharp** to generate PDF files dynamically from Razor templates or HTML content.

---

## 🚀 Features

- Generate PDFs using HTML/Razor views
- RazorLight engine for dynamic template rendering
- PuppeteerSharp (headless Chromium) for precise PDF output
- Swagger/OpenAPI documentation enabled
- Target framework: **.NET 9**
